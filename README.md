# Calgary Infrastructure & Community Growth Pulse

This repository houses a dynamic, operational Power BI desktop report that tracks real-time construction footprints and municipal resource distribution across Calgary's geographic sectors.

## Core Capabilities Developed
* **Live Ingestion Infrastructure:** Configured an automated Web-connection directly to the official Open Calgary Portal API servers to bypass static document limitations.
* **Granular Volume Breakdown:** Analyzed distinct transactional permit keys to aggregate data models exceeding 220,000 distinct public sector rows.
* **Executive Metrics Reporting:** Segmented regional data sets to display real-time updates regarding applicant project types (Residential vs. Commercial) and application lifecycle states.

## Business Value
Designed specifically to empower municipal planning bodies and social-impact non-profits with the clean, scannable data views required for equitable resource distribution and localized asset strategy.
